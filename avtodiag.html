Подключение

Вставьте ELM327 в разъём OBD под рулём, включите зажигание.

Как подключить настоящий адаптер
  1. Откройте приложение в Chrome на Android (или Chrome/Edge на компьютере) по прямой ссылке — см. «Как установить на телефон».
  2. Обычный Bluetooth: в настройках телефона → Bluetooth найдите адаптер (OBDII, V-LINK…), PIN обычно 1234 или 0000. Затем здесь выберите «Bluetooth (обычный)» и адаптер в списке.
  3. BLE-адаптер: сопрягать заранее не нужно — выберите «Bluetooth 4.0» и адаптер в появившемся окне.
  4. Включите зажигание. Первое подключение может занять до 15 секунд — адаптер ищет протокол.
  5. Wi-Fi адаптеры браузер не поддерживает — для них используйте версию для компьютера.
Как установить на телефон

Для работы с Bluetooth страница должна открываться по https прямо в Chrome. Бесплатный способ — GitHub Pages:

  1. Зарегистрируйтесь на github.com (можно с телефона).
  2. Создайте репозиторий, например avtodiag, тип Public.
  3. Загрузите файл приложения (avtodiag.html) и переименуйте его в index.html.
  4. Settings → Pages → Branch: main → Save. Через минуту появится адрес вида https://ваше-имя.github.io/avtodiag.
  5. Откройте его в Chrome → меню ⋮ → «Добавить на главный экран». Получится значок как у приложения.

На iPhone Safari не поддерживает Bluetooth для сайтов. Для BLE-адаптеров можно попробовать браузер Bluefy. Демо и обучение работают везде.
